# Concept: Proof of Nonsense — Bitcoin Emergency Broadcast System

## Decision

Turn the existing static shell into a three-minute, evidence-bearing broadcast. Keep the absurd newsroom framing, preserve strict financial boundaries, and make every sponsor integration visibly honest: **LIVE**, **FIXTURE**, **SIMULATED**, **DRAFT**, or **PENDING**.

This is a **Monitor/Operate** surface, not a marketing landing page. A judge should immediately see the control, the pipeline, the current state, and the evidence.

## Audience promise

Press one button and watch a deliberately over-engineered Bitcoin newsroom:

1. receive a frozen Glimpse probability snapshot;
2. inspect an unsigned Flame draft fixture;
3. calculate a simulated mempool.space rescue estimate;
4. hand deterministic facts to the Proof of Nonsense newsroom;
5. reveal a bilingual broadcast with an audio-ready state.

The joke is the amount of machinery. The facts and safety state remain deterministic.

## Demo contract

**Proof:** A judge can trigger one coherent sequence and distinguish every factual result from fictional commentary.

**Artifact:** A dependency-light static web application driven by the allowlisted `flame-demo-1` case.

**Evidence:** Browser interaction shows the five stages, concrete values, source links, honest state badges, English/German copy, and a final broadcast panel.

**Submission:** Repository, screenshots, three-minute script, challenge/evidence matrix, and separately verified component links.

**Non-goals:** No wallet data, arbitrary transaction input, live payment, invoice creation, signing, broadcast, acceleration submission, real Bitcoin burn, or shared credentials.

## Experience

### Initial state

Above the fold:

- emergency-broadcast title and one-sentence premise;
- a permanent `SAFE DEMO · UNSIGNED · NO PAYMENT` badge;
- the primary `START EMERGENCY BROADCAST` control;
- a compact five-stage pipeline with evidence states.

### Triggered sequence

The control advances through five short stages:

1. **Glimpse snapshot received** — market question, frozen timestamp, probability/range, source.
2. **Flame draft inspected** — PR reference, decode-only status, exact displayed sats.
3. **Fee ambulance dispatched** — simulated bid and explicit no-network/no-invoice status.
4. **Goblin newsroom engaged** — language and presenter state.
5. **Broadcast complete** — deterministic facts, clearly fictional jokes, transcript and audio readiness.

After completion, the control becomes `REPLAY BROADCAST`.

### Result hierarchy

Use two groups instead of six undifferentiated strips:

- **Verified telemetry** — source-backed or fixture-backed values.
- **Authorized nonsense** — comedy lines, visually distinct and explicitly fictional.

## Evidence rules

Every integration declares one state:

- `LIVE`: exercised against the real current service with retained evidence.
- `FIXTURE`: deterministic checked-in public demo data.
- `SIMULATED`: behavior demonstrated without a network or consequential request.
- `DRAFT`: upstream protocol is unfinished or unmerged.
- `PENDING`: named but not yet demonstrated; not eligible evidence.

Sponsor names alone are never treated as integration evidence.

## Safety boundaries

- The case identifier is allowlisted; no arbitrary URL or transaction input.
- No txid, raw transaction, address, wallet label, seed, xpub, key, invoice, payment hash, preimage, or bearer capability crosses the orchestration layer.
- Flame remains decode-only and unsigned.
- mempool.space remains simulated in this application.
- Proof of Nonsense payment state remains independent.
- Facts are rendered deterministically; jokes are visibly separated.
- Invalid cases fail closed with a stable user-facing error.

7. Produce the evidence matrix and run-of-show.

## Acceptance criteria for the first implementation PR

- CTA is visible without scrolling at 390×844 and 1440×900.
- One click produces all five ordered stages and a completed broadcast.
- UI visibly renders the frozen market snapshot, `2,100 sats` Flame value, and `4,200 sats` simulated estimate.
- English and German transcript options work from checked-in deterministic content.
- Every component shows an evidence-state badge.
- Replay works without duplicating content.
- Missing/malformed consumed fields fail validation before rendering.
- Keyboard focus lands on the completed result; `prefers-reduced-motion` is honored.
- No consequential network operation or sensitive identifier is introduced.
- Unit tests and a browser smoke test pass.
